# Gamepad Bridge

A simple, lightweight android app that reads a gamepad plugged into the phone via USB-C and sends its input over Bluetooth to a PC, so the phone behaves like a normal Bluetooth controller, giving new purpose to gamepads that are USB-C only.

## Features
- Live on-screen view of buttons, sticks, D-pad and triggers
- Bluetooth HID gamepad (Android 9+)
- Kotlin, no external libraries

## How to use
1. Open the app and grant the Bluetooth permissions.
2. Plug in the gamepad.
3. Tap "Make discoverable" and pair the phone from the PC's Bluetooth settings.

## Requirements
- Android 7.0+ (Bluetooth sending needs Android 9+)
